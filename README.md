## Run Locally

```powershell
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build Static Files

```powershell
npm run build
```

The production files will be created in `dist/`.

## Before Publishing

Replace these placeholders in `src/main.jsx`:

- `Your Name`
- `your.email@example.com`
- `github.com/your-github`
- `linkedin.com/in/your-linkedin`

The project content is based on hands-on AWS, Terraform, Jenkins, Docker, GitHub Actions, Argo CD learning, and EC2 troubleshooting work.
